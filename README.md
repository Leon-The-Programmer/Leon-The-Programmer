## `The Pattern`

Looking at the projects individually, they might appear unrelated.

Games.  
Trading systems.  
Back-End architecture.  
Different languages.  
Different engines.

But there is a pattern.

I tend to gravitate toward problems where I have to understand **what is happening underneath the abstraction**.

I don't particularly enjoy stopping at:

> *“That's just how the framework works.”*

I usually want to know:

> **Why?**

And then, eventually:

> **What happens if I build it differently?**
